Place Tanger sample tracks here before building the RG35XX payload.

Supported formats:
- `.mp3`
- `.flac`
- `.wav`
- `.ogg`
- `.m4a`

Build with:

```sh
scripts/build-knulli-rescue-payload.sh
```

Or point to another local folder:

```sh
MUSICOS_SAMPLE_DIR=/path/to/tanger/tracks scripts/build-knulli-rescue-payload.sh
```
