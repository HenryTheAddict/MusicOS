# MusicOS desktop guide

MusicOS plays and organizes local music. This guide describes the desktop beta; features marked experimental still need listening or packaged-app acceptance.

- [Importing and rescanning](library.md)
- [Collections](collections.md)
- [Metadata and artwork](metadata.md)
- [Audio, quality, and DJmode](audio.md)
- [Audio Sparklist beta](sparklists.md)
- [Artwork, portraits, and depth](artwork.md)
- [Optional integrations](integrations.md)
- [Troubleshooting](troubleshooting.md)
- [Architecture and verification](../desktop-architecture.md)

Use the links directly on GitHub or in a Markdown reader. No website deployment is needed. Local files, collections, and preferences are retained during rescans. MusicOS does not rewrite source tags as part of audio analysis or portrait/depth processing.
