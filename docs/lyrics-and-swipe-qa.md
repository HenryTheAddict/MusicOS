# Fluid back navigation and lyrics — 2026-10-30 UTC

Implemented on the isolated `codex/desktop-heart-preservation` branch. Android, Wi-Fi schemas, embedded runtime/models and the primary OS checkout are outside this change.

## Behavior and interfaces

- A precise horizontal gesture moves only the current content surface. AppKit supplies finger begin/end/cancel and momentum begin; DOM wheel events retain targeting and control exclusions. A browser wheel fallback settles after 70 ms without input. Release commits at 25% distance or a >=60 px flick at >=0.55 px/ms; commit finishes within 180 ms, cancellation within 140 ms. Reversal, pointer input, dialogs, resize and navigation cancel. Reduced Motion changes route directly.
- Only one inert DOM preview is prepared/mounted. A bounded journal of at most eight serialized route snapshots (4 MB total) supports repeated history returns without retaining live React pages or subscriptions. SVG references are remapped, CSS motion frozen, unloaded images omitted, and saved scroll/theme retained. Pre-parsing occurs after navigation, outside the first swipe event. Regular Back retains its artwork transfer; interactive Back suppresses competing entrance/transfer effects.
- Now Playing title and song menus open Lyrics. Another song is an explicit preview; it never starts playback. The expanded player offers Now playing/Lyrics/Up next and optional native Full screen, restoring the original full-screen state on dismissal. Artwork retains its existing preference.
- Live line/word emphasis follows acknowledged source position and monotonic receipt time; requested but unapplied speed is not used. Seeking uses existing playback commands. Words highlight only with real timestamps. Manual scroll suspends following; Follow lyrics restores it. Hidden/closed consumers unsubscribe, and paused/hidden/closed liquid motion leaves no continuing frame loop.
- One 640×480 resolution-capped canvas liquid scene with authored SVG ribbon geometry and a static SVG fallback uses the current SDR artwork-derived player palette and actual low/mid/high telemetry. No microphone, second decoder, analysis job or upload is involved. The visible scene alone draws; Reduced Motion freezes spatial effects. Small BPM hearts and existing transport geometry remain supplied components.
- The `lyrics` command has typed load/lookup/search/select/parse/import/save/export/history/undo/write_tags actions. Local selections, matching `.lyricsfile`, matching `.lrc`, and embedded lyrics (including detected LRC timing) precede provider lookup. Import/export supports LyricsFile 1.0 with real word timing, line LRC and plain-text import. Plain paragraphs, metadata/offset/language, instrumental state and source attribution survive appropriate round trips. Editing incompatible timed text clears only that line's word data.
- LRCLIB lookups start only on opening missing lyrics or explicit search. A signature includes title/artist/album/duration. Exact matching requires title, artist, album and ±2 seconds; ambiguous/edition variants require selection. Success cache persists; misses expire after 24 hours; Retry bypasses misses. Requests coalesce, serialize with a short delay, identify the configured product, and respect throttling. Late results cannot replace another song.
- `desktop-lyrics-v1.sqlite3`, beside the selected library DB, owns selections/revisions, provider cache, history and export backups. No core library migration or playback-protocol change. Metadata adds a Lyrics workspace with per-song drafts, import/paste, candidate versions, text, line timestamps, stamping and offset. Review saves only lyrics; History supports revision-safe Undo and lazily loaded before/after comparisons.
- Writing plain tags is explicit and reviewed, with freshly enforced paused playback. It reuses tag preflight, durable original backups and recovery locking. FLAC/M4A/MP3/Ogg tests compare decoded PCM, and Undo restores exact original bytes. Unsupported formats retain originals. Synchronized documents stay in musicOS/sidecars. Document Undo and file-tag Undo are separate explicit controls. Exports replace files only after the native save dialog, retaining a backup.

Sources: [LRCLIB API](https://lrclib.net/docs), [lrcget](https://github.com/tranxuanthang/lrcget), [LyricsFile specification](https://github.com/tranxuanthang/lrcget/blob/main/LYRICSFILE_CONCEPT.md). No lrcget code or application is bundled, and no publishing API is called.

## Player control refinement

The Motion toggle is removed. Player tabs, top actions and lyric source/edit controls fade out after 2.2 seconds idle, without any content reflow. Pointer movement, keyboard focus or a touch reveals them; the first touch is consumed so it cannot seek accidentally. Menus and keyboard-focused controls stay visible. One timeout is cleared on hide/unmount; no idle animation loop is added. Playback transport remains visible.

Fullscreen and Exit Fullscreen are exported from the current Sketch document, artboards `7EF367C1-94AA-4C52-A62F-573CD646F4C4` and `1F6956D4-F2BF-49FB-8850-5C627A5BD4B6`.
